# XRPL Tax for Cryptact

XRP Ledger のウォレットの取引を、クリプタクトの入力欄（カスタムファイルの行）に仕訳するツールです。
ブラウザだけで動きます（サーバーなし・インストール不要）。

- **XRPL タブ**：FXRP のミント・償還の手数料（Smart Accounts 含む）、DEX のスワップ、AMM・Doppler Vault の預け入れ・引き出し、トークンの受け取り（報酬・エアドロ）、登録していない相手との送受金、ウォレット間の送金
- **xrp.cafe タブ**：xrp.cafe で売買・ミントした NFT（カスタムトークンとして手入力する項目）

## 使い方

1. ページを開き、ウォレット（XRPL アドレス、最大20件）を登録する
2. 期間を選んで「取引を取得する」
3. 行ごとに内容を確認する（「要確認」の行は Action や価格を決める）
4. チェックした行を CSV でダウンロードし、クリプタクトの「カスタムファイル」として取り込む

手元で使うときは `index.html` をブラウザで開くだけで動きます。

## データの扱い

- 登録したウォレット・トークン設定・アドレス帳は、**使っている人のブラウザの中（localStorage）にだけ**保存されます。
  このツールにはサーバーがなく、ほかの人や作者に送られることはありません。
- 「ファイルに保存」で書き出した JSON は、自分の PC に保存されるだけです。
- 取引の取得では、ブラウザから次の公開 API に直接問い合わせます（どれもブロックチェーンや相場の公開データです）。

| 用途 | 接続先 |
|---|---|
| XRPL の取引履歴 | s2.ripple.com / s1.ripple.com（つながらない場合 xrplcluster.com / xrpl.ws） |
| FXRP の数量・手数料の照合 | flare-explorer.flare.network / songbird-explorer.flare.network |
| XRP の円換算 | public.bitbank.cc |
| NFT の画像・名前（xrp.cafe タブ） | ipfs.io / gateway.pinata.cloud |

## 計算の考え方（要点）

- **FXRP** は XRP を Flare に橋渡ししたものとして、クリプタクトでは **XRP として扱う**（初期設定）。ミント・償還は入力不要で、手数料だけを DEFIFEE（XRP）で記録します。
  FXRP に切り替える設定（リブランド）も選べます。
- **AMM・Doppler Vault** は差分計上：預け入れ＝LEND、元本までの引き出し＝RECOVER（どちらも損益なし）、元本を超えた分＝BONUS、戻らなかった元本＝LOSS。
- **円換算**は決まった順で求めます：クリプタクトの対応コイン → XRP との取引 → 同じ取引内の XRP 経由 → 直前の AMM の比率 → 手入力。XRP/JPY は bitbank の公開ローソク足。根拠は各行のコメントに残します。
- クリプタクトの対応コインかどうかは、トークン一覧で確認・保存できます（よく使うものは確認済みとして組み込み済み）。

詳しくは画面下の「計算ルールと判定のしかた」を見てください。

## 公開と限定公開（アクセスコード）

`main` への push、または Actions タブの「Run workflow」で GitHub Pages に公開します（`.github/workflows/deploy.yml`）。

限定公開は **GitHub の設定だけで切り替えられます**（コードの変更は不要）。
`Settings → Secrets and variables → Actions` で:

| 設定 | 種類 | 値 |
|---|---|---|
| `ACCESS_CODE` | Secrets | アクセスコード（全角・大文字・前後の空白は区別しない） |
| `ACCESS_GATE` | Variables | `on`（コードが必要） / `off`（誰でも閲覧可） |

変更後は Actions → Deploy → Run workflow で反映します。一度コードを入れた端末は記憶されます。

> 簡易的な鍵です。ページのソースは公開リポジトリにあるため、仕組みとしては回り込めます（扱うデータはすべて利用者のブラウザ内と公開データのみ）。
> 鍵がオンの間は検索エンジンに載らないよう `noindex` を付けています。
